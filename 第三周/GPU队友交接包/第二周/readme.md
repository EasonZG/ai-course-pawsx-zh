## M2 · 数据与基准

### 1.这一步做什么
把数据和判分规则定下来：哪些数据平时调试用、哪些留到最后验收，每条答案怎么算对。

### 2.要求
把数据分成两份：一份开发调试用，一份留到最后验收（最后那份别拿来调参）。
写清判分规则：每条答案怎么判对错（完全一样、包含关键词、数值误差范围、多个答案算对几个）。
报告里说明数据从哪来、多少条、有没有明显偏斜（比如某一类特别少）。

### 3.要交的东西
造基准的报告（按实验报告模板四节写：目标与完成情况、核心材料、问题分析与改进、分工安排）
数据说明与判分规则说明（写在上面那份报告里即可，不用另交字段清单或 manifest）
补充材料（可选：划分文件、判分规则文件、冻结记录）

### 4.验收标准
开发与测试分离，数据划分、指标与版本冻结。
