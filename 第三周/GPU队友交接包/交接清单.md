## 1. 这个包是什么

本包用于把第三周 M3 交给有 NVIDIA GPU 的队友。包含前两周完整材料、第三周 README 与 Word 模板、原始课程包、新的 GPU 执行流程、给接手 agent 的开场提示、本清单和 SHA256 校验文件。

**不是**完成版 M3：包内没有已训练的 BERT、没有 M3 逐条预测、没有 M3 指标、没有 M3 Word 报告。原课程包里的 `report/M3.md` 仍是空白模板，`oj/run.py` 仍是词面重合对照；这些都不能当作 M3 已完成。

## 10. 重要边界

1. **平台 test 400 分数只能在真实平台评测后填写**；题目卡的 0.6975/0.74 是教师参考值，不是本组成绩。
2. **holdout746 只评一次**；看结果后不得重新选模、改阈值或替换 checkpoint 再称首次留出。
3. **test_inputs / compare50 无标签**；只验证输出完整性、格式、覆盖率和运行时间，不报虚构 accuracy。
4. **传统轨不调用 LLM**；推理 `usage` 四项全 0。BERT 微调属于允许的小模型训练，但不得用外部测试答案。
5. **不得修改 M2 冻结文件**；如平台只接受固定 `oj/run.py`，先确认平台约束，再在最终平台包做适配入口并保留完整 M2 原包与哈希记录。
6. **未经人工复核不得写“组员已交叉验证”**；原分工与实际完成记录分开写。
7. **不得把本清单、空白模板、历史基线或本机 CPU 中间产物当成完成证据**；最终状态只能是“待人工/平台验收”。
