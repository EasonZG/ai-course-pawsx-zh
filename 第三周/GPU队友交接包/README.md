# GPU 队友交接包

**状态：待 GPU 实现、训练与验收。不是完成版，不能作为 M3 已完成的证据。**

本包把第三周 M3 的原始课程材料、前两周成果、执行流程和审查要求交给有 NVIDIA GPU 的队友。接手方应在 `第三周/M3_提交包/` 中完成真实训练、选模、一次 holdout 评测、错误分析、四节报告和可携带打包，并按 `GPU交接_工作流程与审查方式.md` 第 7 节回传。

## 先读什么

1. `AGENT.md` 或 `AGENTS.md`：给接手 agent 的简明指令。
2. `GPU交接_工作流程与审查方式.md`：唯一执行依据。
3. `交接清单.md`：包内容、排除项、原始数据哈希与回传清单。
4. `给GPU队友Agent的开场提示词.md`：可直接粘贴的开场提示。
5. 前两周报告、第三周 README/Word 模板、原始课程包题目卡与 M2 报告。

## 包含什么

- `第一周/`：选题报告、模板、汇报稿与演讲稿。
- `第二周/`：实验报告、补充材料 zip、readme 与模板。
- `第三周/`：README、Word 模板、执行记录模板。
- `pawsx_zh/T4-PAR-中文改写语义一致性/`：原始课程包，含冻结数据、判分脚本、M2 报告与 M3 空白模板。
- 流程、清单、开场提示和 SHA256 校验文件。

## 明确不包含

原工作区的 `.venv-m3`、`work/`、CPU 实施副本 `M3_提交包/`、缓存、`__pycache__`、`.pyc`、未验收的 CPU 模型/预测/日志，以及任何声称已完成的 Word 报告。它们不属于交接主线，也不能作为 M3 完成证据。

## 校验

在包根目录运行 `sha256sum -c SHA256SUMS.txt`（Linux）或逐行核对 `SHA256SUMS.txt`（Windows）。原始数据 5 个文件、冻结划分 2 个文件，以及冻结清单全部 17 项均已核对一致；详见 `交接清单.md`。

## 边界

不得修改原包与 M2 冻结文件；不得使用平台 test/compare 标签；不得把题目卡参考值写成实测；不得伪造 GPU 训练、日志或报告。所有路径均相对本包根目录。
