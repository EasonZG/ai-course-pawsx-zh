## 2. 你要交什么

三种方法、**一个统一入口**（平台用同一个包、同一个脚本，只换 `--method` 调用三次）：

| 方法 | 要求 | 硬性检查 |
| --- | --- | --- |
| 传统方法 `trad` | 至少一种与课程内容相关的 AI 方法，说明表示/算法/参数/边界 | 不许调 LLM：`usage.tokens_in` 必须为 0 |
| 单 LLM 基线 `llm` | 固定提示词与模型，单次调用出答案 | 每例**恰好一次**调用，不许用工具/检索 |
| Agent `agent` | LLM + Tool + State + Execution Loop，真实调用工具并读返回 | 至少一次真实工具调用，轨迹可回放 |

## 3. 输入

每行一个 JSON，至少含：

| 字段 | 说明 |
| --- | --- |
| `item_id` | 唯一 ID，必须原样回填 |
| `task` | `single_label` |
| `text_pair` | 两句文本 [句1, 句2]（判断是否同义） |


**本包所有数据文件（train / validation / dev100 / test_inputs）都用同一个扁平格式**，与平台判题喂给入口的格式完全一致：

```json
{"item_id": "clinc-train-123", "task": "single_label", "text_pair": ["句1", "句2"], "target": {...}}
```

（原始教师包用的是 `{"id","input":{...},"target"}` 嵌套写法，内容等价；这里已统一，避免第一天就踩 KeyError。）

## 4. 输出（写进 `results.jsonl`，每行 5 个键）

```json
{"item_id": "...", "output": {"label": 0}, "status": "ok", "latency_ms": 12, "usage": {"tokens_in": 0, "tokens_out": 0, "cost": 0.0, "tool_calls": 0}}
```

`output` 的形状：`{"label": <整数下标>}`

输出空间是 2 个类别的**整数下标**（下标就是 `data/metadata.json` 里 `labels` 的顺序）。写成 `"bill_due"` 这种标签名会被判无效。

- 失败的样也要写一行（`status` 取 `fail|timeout|error`），**不要丢行**：分母是全部测试题，丢行等于自己扣分。
- 每写一行就 `flush()`：平台超时会 kill 进程。
- `usage` 如实填（`tokens_in/tokens_out/cost/tool_calls`），教师按这个核算调用成本。

## 7.6 这道题的实测阶梯（务必先看，能省你两天）

教师实测过下面这些做法。**注意每行的切片标注**：平台判题用的是 test 400
（`manifest.splits` 的最后一项），compare 50 只用于三轨横向比较——两者不能混读。

| 做法（切片） | accuracy |
| --- | ---: |
| 词语重合阈值（本例 `oj/run.py`，test 400） | 0.5575 |
| guess_majority（退化）（compare 50） | 0.525 |
| 冻结bert mean+LR（compare 50） | 0.46 |
| 冻结bert CLS+LR（compare 50） | 0.52 |
| 字符TF-IDF+SGD（cheap smoke）（compare 50） | 0.58 |
| 微调bert（2ep, lr3e-5, bs32, train20000, len96）（test 400） | 0.6975 |
| 微调bert（3ep, lr2e-5, bs32, train44898, len64）（compare 50） | 0.74 |

**结论**：**冻结编码器在这道题上无效**（0.46–0.52，≈ 猜多数类），字符/词语特征也不够（0.58）。
必须**微调**（或至少训练到任务相关的参数上）才能越过 0.6675 的门禁。

为什么：PAWS-X 的训练集是**机器翻译**、验证/测试是**人工翻译**；
而且对手句对用词高度重合，标签取决于细微的语序/指代差别——这些冻结特征学不到。
（实测：冻结特征在训练集内能到 0.75，但换到测试集就掉回 0.52，是典型的过拟合。）

**算力提示**：全量微调 bert-base-chinese（3 epoch、bs32、len64）在单张 RTX 2080 Ti 上约 **9.5 分钟**。
本机无 GPU 的小组请走 lab 任务容器；CPU 上微调不现实，别硬扛。

## 11. 诚实边界（写报告时必须承认的事实）

- 官方 test 标签上游已公开，**不是真隐藏集**；答辩现场的新输入才是真正的防过拟合手段。
- 数据是课程清洗版，结果**不得**与论文原始成绩横向比较。
- 切片很小：50 条配对比较只能可靠检出约 **12pp** 以上的差异；汇报差异时必须给区间（`selfcheck` 输出里带了指标，报告里请给 bootstrap 区间）。
- 本数据集已知的数据特性：PAWS-X 字符词袋基线低于多数类，必须用预训练语义模型。
